## ADR-0003: Karpathy 원칙 흡수 — 수술적 변경·단순성·가정 명시
- 날짜: 2026-04-29
- 상태: 채택
- 기원: 없음 (외부 레퍼런스 — github.com/forrestchang/andrej-karpathy-skills)
- 맥락: Andrej Karpathy가 관찰한 LLM 코딩 3대 실패 패턴 중 Venom이 명시적으로
  다루지 않던 부분이 있었음. (1) 기존 dead code vs 내가 만든 고아의 구분 부재,
  (2) 단순성 우선 기준이 선언만 있고 구체적 검사가 없음, (3) 가정을 드러내지
  않고 조용히 해석해 진행하는 문제가 규칙화되지 않음.
- 결정:
  1. `00-core.md` 규칙 9·10 신규: 수술적 변경(내 고아만 정리, 기존 dead code는
     보고만) + 가정 명시(트레이드오프 노출, 역제안).
  2. `10-coding-standards.md` 구조 섹션: "단순성 우선" 항목 추가(시니어 테스트).
     죽은 코드 섹션: 내 것 vs 기존 것 명확 구분.
  3. `CLAUDE.md` 의무 루프: "이해+가정선언 → 성공기준정의" 앞단 추가. 각 단계
     구체화.
- 결과:
  장점: LLM 3대 실패 패턴(숨은 가정·과잉 복잡도·불필요한 사이드이펙트)을
  규칙 레벨에서 명시적으로 차단. 코드 리뷰 시 "요청 추적 가능성"이 기준이 됨.
  단점: 규칙이 늘어남. 단, 이 3개는 기존 규칙과 중복 없이 새 영역을 다룸.
